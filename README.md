# 학생 성적 데이터 탐색

`StudentsPerormance.csv` 파일을 업로드해 인종/민족과 부모 학력별 학생 수를 그래프로 확인하는 Streamlit 앱입니다. CSV에는 `race/ethnicity`와 `parental level of education` 열이 있어야 합니다.

## 실행 방법

필요한 패키지를 설치합니다.

```bash
python -m pip install -r requirements.txt
```

앱을 실행합니다.

```bash
python -m streamlit run streamlit_app.py
```
